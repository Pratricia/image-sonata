# 其它"无意义但好听"的唱法

塔语（Hymmnos）是最"有语法"的一支。除此之外还有几类完全不同的做法，各自的听觉特征不一样，正好可以给我们的风格系统当参考。

---

## 1. Hopelandic / Vonlenska（Sigur Rós）

- **是什么**：冰岛乐队 Sigur Rós 主唱 Jónsi 自创的"假语言"，冰岛语叫 Vonlenska（希望语），英文叫 Hopelandic。
- **用法**：不表达具体词义，只承载旋律与音色；Jónsi 说它是"一种还没成形的语言"，用来让听者自己填空。
- **代表**：《( )》整张专辑（曲目无名，全是 Hopelandic）、《Hoppípolla》副歌。
- **听觉特征**：
  - 大量 `a / o / e` 长元音，辅音极少且轻（h、l、v、m）；
  - 音节长度跟着旋律走，**一个音节可以拖满一个长音**（和我们之前"一个音不能拖太长"的规则相反——这是风格差异，不是对错）；
  - 用假声（falsetto）在高音区唱，声音薄、飘。
- **可借鉴**：慢速、氛围型（对应我们的 `cinema` / `minimal` 风格）可以放松"音节必须短"的规则，允许 1 个音节 = 2–3 拍。

## 2. Kobaïan（Magma）

- **是什么**：法国前卫摇滚乐队 Magma 的鼓手/主创 Christian Vander 创造的语言，有一套完整词汇和语法（据说是"未来人类在 Kobaïa 星球的语言"）。
- **用法**：整张专辑用 Kobaïan 演唱，歌词有实际含义但听众不懂。
- **听觉特征**：
  - 辅音密集、有明显的"硬"辅音（k、t、z、g），节奏感强；
  - 合唱段落多，像"仪式/圣咏"；
  - 情绪偏宏大、戏剧化。
- **可借鉴**：`tense` / `electro` 风格可以用更硬的辅音（k/t/z/g）和短促音节，做"咒语感"。

## 3. Lisa Gerrard 的 idioglossia（Dead Can Dance）

- **是什么**：Lisa Gerrard 自创的"私人语言"（idioglossia，语障/私语的意思），她说自己从 12 岁开始这样唱，是"从另一个地方来的声音"。
- **代表**：Dead Can Dance《Sanvean》、《The Host of Seraphim》；电影《角斗士》的《Now We Are Free》。
- **听觉特征**：
  - 低音区、胸腔共鸣厚；
  - 元音偏 `a / o`，尾音下沉；
  - 装饰音多、有中东/巴尔干式的微分音滑音；
  - 完全不像"说话"，像"乐器化的嗓音"。
- **可借鉴**：`folk` / `cinema` 用低音区 + 长滑音 + 少辅音，会非常"史诗"。

## 4. Cocteau Twins（Liz Fraser）

- **是什么**：歌词其实是英文，但被刻意唱得含糊、切分、混响淹没，听感上等于无意义音节。
- **听觉特征**：气声多、辅音几乎被吞掉、大量滑音。
- **可借鉴**：`lofi` 风格可以**故意降低辅音音量、加混响**，让"词"退化成"音色"。

## 5. Loxian（Enya / Roma Ryan）

- **是什么**：词作者 Roma Ryan 为 Enya 的《Amarantine》专辑造的语言，有词根和语法，灵感来自"未来/外星"。
- **听觉特征**：非常"圆"，元音为主，辅音柔和，慢速多层叠加。
- **可借鉴**：多层人声（自己给自己唱三度/五度）——我们已经做了 A′/A″ 的和声，可以再加"同词不同八度"的层。

## 6. Scat singing（爵士拟声）

- **是什么**：Ella Fitzgerald、Louis Armstrong 用 `doo-be-doo`、`shoo-bee-doo` 这类音节即兴，本质是"用人声模仿乐器"。
- **听觉特征**：辅音硬（b、d、t、sh）、节奏切分强、音节极短（0.1–0.2 s）。
- **可借鉴**：`electro` / 快节奏段落可以用 scat 式短音节，和慢速段形成对比。

## 7. Joik（萨米人）

- **是什么**：北欧萨米人的传统吟唱，不是"唱某个人"，而是"用声音描绘某个人/动物/地方"。
- **听觉特征**：音节极少、大量重复、喉音与鼻音共鸣。
- **可借鉴**：`minimal` 风格可以只用 3–4 个音节循环，靠音色变化推进。

## 8. 横向对比

| 类型 | 辅音密度 | 音节长度 | 音区 | 情绪 | 对应我们的风格 |
|---|---|---|---|---|---|
| Hymmnos 塔语 | 中 | 中（0.2–0.5 s） | 中高 | 起伏大、叙事 | `cinema`、`folk` |
| Hopelandic | 极低 | 长（可 1–2 s） | 高（假声） | 飘、朦胧 | `cinema`、`minimal` |
| Kobaïan | 高 | 短 | 中 | 宏大、仪式 | `tense`、`electro` |
| Gerrard idioglossia | 低 | 长 | 低 | 悲、庄严 | `folk`、`cinema` |
| Cocteau Twins | 极低（被混响吞） | 中 | 中 | 梦、暧昧 | `lofi` |
| Loxian | 低 | 中长 | 中高 | 纯净、圣洁 | `musicbox` |
| Scat | 高 | 极短 | 中 | 活泼、即兴 | `electro` |
| Joik | 极低 | 中 | 低 | 原始、循环 | `minimal` |

## 9. 共同规律（这才是"为什么好听"的答案）

1. **元音承载音色，辅音只负责"起音"。** 所有例子都以元音为主，辅音是点缀。
2. **音节长度必须服从旋律。** 同一个"词"在快歌里被切成 4 段、在慢歌里拖成 2 拍，都正常。**没有"一个音节固定多长"这回事。**
3. **重复产生"语言感"。** 同一串音节反复出现，听众就会以为它有含义（Hymmnos 的副歌、Joik 的循环都是这样）。
4. **句尾要"落"。** 无论哪种，乐句最后一个音节几乎都会拖长 + 渐弱 + 音高微降。
5. **人声要有"位置"。** 要么在正中（主唱），要么极左/极右（和声层）。挤在中间会和主奏打架——这是我们之前"听不见人声"的真正原因之一。

## 10. 给我们引擎的扩展建议

现在的 `voxV()` 是"一种嗓子唱所有风格"。可以按风格切换**唱法预设**：

```js
const VOICE_STYLE = {
  hymmnos:  { consRate: 0.55, sylMin: 0.22, sylMax: 0.50, vib: 32, breath: 0.05, oct: 0 },
  hopeland: { consRate: 0.25, sylMin: 0.45, sylMax: 1.20, vib: 26, breath: 0.10, oct: +12 },
  kobaian:  { consRate: 0.75, sylMin: 0.14, sylMax: 0.30, vib: 18, breath: 0.02, oct: 0 },
  gerrard:  { consRate: 0.30, sylMin: 0.40, sylMax: 1.00, vib: 40, breath: 0.08, oct: -12 },
  scat:     { consRate: 0.85, sylMin: 0.10, sylMax: 0.22, vib: 8,  breath: 0.02, oct: 0 },
};
```

再由 `spec.style`（cinema / folk / electro / lofi / minimal / musicbox / tense）挑一个预设。
这样"换风格"就不只换鼓和音色，**连唱法一起换**，不同照片的差异会更明显。
