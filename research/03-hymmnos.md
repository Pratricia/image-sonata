# 塔语 · Hymmnos

> "塔语"是中文圈对 **Hymmnos（ヒュムノス語）** 的俗称，出自 GUST / 万代南梦宫的 RPG《アルトネリコ》（Ar tonelico，2006）系列。它是"塔"（Ar tonelico / Ar Ciel）世界里用来施法的"诗"，所以被叫成塔语。

调研时间：2026-10

---

## 1. 它是什么

- **性质**：完整的人工语言（conlang），有词汇表、语法、方言，不是"随便哼的音节"。
- **创作者**：土屋暁（Akira Tsuchiya），系列总监；现实世界里最熟悉这套语言的是歌手/作词 **志方あきこ**。
- **设定**：塔语是"情感的語言"。语句以**说话者的情绪**开头，情绪不同，同一句话对"塔"的作用也不同——这是它最核心的设定，也是它听起来"每句都在倾诉"的原因。
- **使用方式**：几乎只用于**歌唱**与咏唱。现实中没有日常口语记录，只有制作发表会上志方あきこ用塔语打过招呼。

### 与"胡言乱语"的区别

| | 塔语 | 随便哼（la-la） |
|---|---|---|
| 有词汇 | ✓ 数千词 | ✗ |
| 有语法 | ✓ 情绪前缀 + 动词 + 宾语 | ✗ |
| 听众能懂 | ✗（要靠官方/粉丝词典翻译） | ✗ |
| 听感 | 有起伏、有句法、像在说一件具体的事 | 容易变成无差别元音 |

**关键洞察：因为它"有语法但听不懂"，所以既保留了语言的情绪轮廓，又不占用听众的理解带宽。** 这正是我们做"无意义音节人声"想要的效果。

## 2. 语法核心：想音（Emotion Sound）

一句话的结构：

```
[想音 Emotion Sound] - [动词] - [宾语] - [补语]
```

想音固定是**三个词**，分别表示 **程度 / 情绪 / 愿望**：

```
[first: 程度] - [second: 情绪] - [third: 愿望]
```

### 2.1 第一个词：程度

| 词 | 含义 |
|---|---|
| Rrha | 恍惚、出神（trance-like） |
| Was | 非常 |
| Wee | 适度、合理 |
| Fou | 一点点 |
| Ma | 随意的、不强求 |
| Nn | 不情愿 |

### 2.2 第二个词：情绪

| 词 | 含义 | | 词 | 含义 |
|---|---|---|---|---|
| i | 焦躁 | | granme | 想保护、勇敢 |
| yea | 高兴 | | touwaka | 抱有希望 |
| waa | 高兴（另一种） | | quel | 急切、拼死 |
| paks | 兴奋、紧张 | | yant | 害怕 |
| num | 无（平静） | | guwo | 愤怒、怨恨 |
| ki | 专注、凝神 | | jyel | 孤独 |
| wol | 炽热、狂热 | | zweie | 坚定、真诚 |
| apea | 被幸福笼罩 | | au | 悲伤 |

### 2.3 第三个词：愿望

| 词 | 含义 |
|---|---|
| ga | 我希望这停止 |
| ra | 我希望这继续 |
| erra | 我希望这永远继续 |
| wa | 我可以忍受 |
| gaya | 我希望这再也不要发生 |
| gagis | 我无所谓 |

### 2.4 例句

```
Was  yea  ra   chs   hymmnos  mea
 │    │    │    │      │       └─ 我
 │    │    │    │      └───────── 诗 / 歌
 │    │    │    └──────────────── 成为
 │    │    └───────────────────── 希望继续
 │    └────────────────────────── 高兴
 └─────────────────────────────── 非常
```

> "我非常、高兴地、希望一直唱下去。" —— 直译大概是"我很高兴能以歌表达自己"。

注意它的语序：**情绪在最前面，动词在中间，宾语在最后**。中文/英文都不是这样，所以听起来"陌生但合理"。

### 2.5 其它结构

- **外部视角**：`[想音]-[动词]-rre-[主语]-[动词]-[宾语]`，`rre` 是主语标记。代词有性与数：`yor/yorr`（你）、`has/harr`（她）、`hes/herr`（他）。
- **持续想音**：`Ma num ra 0x vvi.` 开始，`1x AAs ixi.` 结束，中间所有句子共享同一个想音。**这非常适合"一段副歌共用一个情绪"**。

## 3. 为什么它唱起来好听（音位学观察）

以下是**从歌词里观察到的规律**，不是官方音系表：

1. **开音节为主**：绝大多数音节是 `辅音 + 元音`，很少以辅音收尾（收尾多是 n / m / l / r / s）。
2. **元音密度极高**：`faura`、`yerwe`、`soare`、`mea`、`ciel`——几乎每个辅音都跟着元音，唱起来"连贯不卡"。
3. **辅音偏柔**：l / r / n / m / w / y / s / f / v 占主导；爆破音（t/k/p/d/g/b）少，且多出现在词首。
4. **大量双元音与滑音**：`ea`、`ie`、`ae`、`ou`——正好是"装饰音"最容易发生的位置。
5. **词尾几乎总是开元音**，所以每个词都可以自然地拖长（这是"咏唱感"的来源）。
6. **重复**：`Faura yerwe ... Faura sonwe ...`（小鸟啼…小鸟唱…）这种排比在歌词里非常常见，和音乐的模进（sequence）天然对齐。

**一句话：它不是"随机音节"，而是被设计成"适合人声长音 + 适合排比"的音节系统。**

### 唱法特征（志方あきこ）

- 真假声切换频繁，高音多用**假声/气声**，不是实唱。
- 大量**上行滑音**进入长音（从低半音/全音滑上去），落音后加**延迟颤音**。
- 长音上常有**元音微变**（a → 略带 o），不是一成不变。
- 多层**自己给自己和声**（三度、五度、八度），人声本身当"弦乐铺底"。

这四点，我们的 `voxV()` 目前只做到第 2 点（起音上滑 + 延迟颤音）。

## 5. 我们能直接借用什么

> 版权提醒：**歌词文本受版权保护，不能抄。** 可以借的是"音位系统"和"语法结构"，这两样是语言规律，不是作品表达。

### 5.1 音位表（用于生成音节）

```
声母 onset：（无）f h l m n r s v w y sh th k t d p b g z j ch
韵母 nucleus：a e i o u ae ea ie ou ai
韵尾 coda：（无）n m l r s
```

生成规则（建议按此实现）：

1. 每个音节 1–2 个 mora，`onset + nucleus (+ coda)`；
2. **韵尾出现概率 ≤ 20%**，且只能是柔辅音；
3. **词尾必须是开元音**（保证能拖长）；
4. 一个"词" 2–4 个音节，一句 3–6 个词；
5. 相邻音节**不要重复同一个声母**（避免"哒哒哒"）。

### 5.2 想音 → 音乐参数（这是最有价值的映射）

把"想音三元组"变成我们谱面生成器的输入，一个乐句一个三元组：

| 想音成分 | 影响 |
|---|---|
| **程度**（Rrha/Was/Wee/Fou/Ma/Nn） | 力度 vel（0.55–1.0）、是否加和声层 |
| **情绪·正向**（yea/waa/apea/touwaka/wol） | 大调色彩、上行旋律、元音偏 a/e、颤音幅度大 |
| **情绪·负向**（au/jyel/yant/guwo/i） | 小调色彩、下行旋律、元音偏 o/u、气声比例高 |
| **情绪·中性**（num/ki/zweie/granme） | 平稳、长音、少装饰 |
| **愿望 ra / erra** | 句尾**不解决**（停在第 2/5 级或悬置音），`erra` 再加长音渐弱 |
| **愿望 ga / gaya** | 句尾**下行解决到主音**，短促收束 |
| **愿望 wa / gagis** | 句尾停在任意音，不做处理（最"平"） |

这套映射的好处：**它给"每句的情绪"提供了一个离散的、可复现的随机源**，比"随机选个元音"有说服力得多，也更容易在界面上解释给用户听。

### 5.3 音节与音符的对齐

观察真实塔语歌曲：

- 一个词（2–4 音节）通常对 **1–2 个音符**，快速段落才一词一音对一音节；
- **长音一定落在开元音上**（通常是词尾）；
- 乐句最后一个词会**拉长到 2–4 拍**，前面的词密集。

对应到我们已有的规则：`score.js` 里"按 0.33 s 切音节、每 2 小节换气"保持不变，只需要把**音节表**换成上面的音位表，并把**词尾音节强制设为开元音 + 更长时值**。

> **修正（v3）**：上面这条"按 0.33 s 均分"是错的，做出来就是"啊-啊-啊"。
> 真人唱长音是**一个元音拖住**，不是在同一个音高上反复切。
> 现在的做法见 §5.4。

### 5.4 连唱模型（v3 已落地：为什么不能"一个音节一次起音"）

第一版是"一个音节 = 一个振荡器 + 一次起音衰减"。听感直接变成 **"啊、啊、啊"**——因为每次起音都是一次呼吸：
音量从 0 涨到峰值再衰减，音节之间还有 20% 的静音缝。真实唱歌里，**只有换气**才这样。

现在的模型（`audio.js` → `voxV()`，`score.js` 人声段）：

| 层 | 规则 |
|---|---|
| 事件粒度 | **一个音符 = 一个"词"**，事件里带 `syl: [{u,d,m,v,cons}]`（相对秒数 / 时值 / 音高 / 元音 / 字头辅音） |
| 音节数 | 按时值定：<0.5s 一字、<1.0s 两字、<1.7s 三字、更长四字（**不是** 每 0.33s 切一刀） |
| 时值分配 | 前 n−1 个音节短（≤0.32s），**最后一个音节吃掉剩下的全部时间** → 词尾拖长 |
| 发声单元 | 按**元音**切段，同元音的音节共用**一个振荡器**（音高在段内滑过去） |
| 换元音 | 70ms **交叉淡化**（两个振荡器同时存在、一进一出），相当于口型从 a 变到 i 的过程 |
| 换词 | 只有这里才重新起音；是否"连唱"看上一个词离这个音起始是否 <0.1 拍——连唱时从 55% 音量直接进来 |
| 辅音 | 只在**字头**（词首 80%、词中 30%），音量压到元音的 ~20%，时长 40–70ms |
| 颤音 | 一段共用一条 5.3Hz LFO，**延迟 0.2–0.55s 才进来**（真人先直后抖） |

结论一句话：**"像人唱"的分界线不是音色，而是"一口气唱完一个词，只有换词/换气才重新张嘴"。**

### 5.5 人称与功能词（v15 落地）：为什么我们的声音"只剩元音"

**用户反馈**："现在就是那种像是纯 a o e y w u 的感觉，听起来不像一种语言。"

#### 1）先看塔语怎么用"人称"

查 Hymmnoserver 的语法（§7 第一条），它的句子是：

```
[想音 · 三个词] - [动词] - [宾语/补语]
Was      yea      ra       chs      hymmnos      mea
程度     情绪     愿望     动词     宾语         人称（我）
```

- **人称不是一个"格变化"，而是几个极短的词**，挂在句子末尾或 `rre`（主语标记）后面：

  | | 宾语形 | 主语形 | 音节数 |
  |---|---|---|---|
  | 我 | `mea` | （默认第一人称，可省） | 2（me-a） |
  | 你 | `yor` | `yorr` | 1（带韵尾 -r） |
  | 他 | `hes` | `herr` | 1（带韵尾 -s） |
  | 她 | `has` | `harr` | 1（带韵尾 -s） |
  | 我们 / 你们 / 他们 | `yora` / `yora` / `hers` | `yorra` / `herra` | 1–2 |

  词典里 `infel yor`（谢谢，字面"你的爱"）、`sarla mea`（我的歌）都是这个用法：
  **人称是句尾的短词，不是句首的长词。**

- **想音固定三个词、固定位置、每句都来一遍**：`Was yea ra` / `Wee touwaka erra` / `Ma num ra`。
  这三个词本身很短（1–2 音节），而且 `Was` / `gagis` / `chs` / `rre` 都带**韵尾或辅音簇**。

**这两个结构才是"语言感"的来源**：出现频率最高的一批词，永远出现在同一个位置，
而且它们比实词更短、辅音更硬。听众听不出意思，但听得出"这里在说语法"。

#### 2）我们的病：只有实词，没有功能词；只有开音节，没有韵尾

改前实测（`score.js` 的 `e.syl`，排除转音/滑音）：

| | 音节 | 带声母 | 韵尾 | 阻塞音（t/k/s/sh/f…） |
|---|---|---|---|---|
| 黎明海面 | 80 | 66% | **0** | 10% |
| 夜之城 | 115 | 71% | **0** | **2%** |
| 森林 | 136 | 62% | **0** | 8% |

- **韵尾 0%**：每个音节都是 `CV` 或 `V`，整首歌是"元音—元音—元音"，中间只夹着 l/n/m/w/y/v/r/h。
- **阻塞音 2–10%**：`MOOD_SOFT_CONS` 只有 `l n m v w y h r`，**全是响音**（近音+鼻音），
  它们和元音在频谱上几乎连着 —— 听感就是一条元音线。
- **库存里 `w/h/l/m/r` 占了 60% 以上**：`h` 是气声、`w` 只是 u 的滑音。

结论：不是音色问题，是**音位构成**问题。语言里元音和辅音大致 1:1，我们大概 5:1。

#### 3）改法（v15，全部在通用引擎里）

1. **补韵尾**：`LEX` 的每个音节带 `cod`（词中 40%、词尾 18%），
   取自 `n / n / l / l / r / r / s / m / t / k`（鼻音最多，塞音最少 —— 语言里就是这个分布）。
2. **音频层真的把音节"关上"**（`audio.js` `voxV`）：元音在最后 55–75ms 收到 28%，
   噪声韵尾填进这个缺口。**不切这一刀是没用的** —— 只在元音后面加噪声，
   耳朵会把它算成下一个字的声母，听起来反而更"平"。
   塞音韵尾用"闭气 + 极轻除阻"（汉语入声、日语促音就是靠这个闭气）。
3. **句首唱想音**：`[程度] + [愿望]`（如 `Was ra` / `Wee erra`），每个乐句开头都唱。
   用的是这一首**已经推导出来的想音**（`spec.voxMood`），界面上本来就写着 —— 现在它真的被唱出来了。
4. **句尾挂人称**：`mea` / `yor` / `hes` 按乐句轮换（同位置永远同一人称）。
   `yor` / `hes` 自带韵尾 `-r` / `-s`，正好补上词尾辅音。
5. **辅音库存去响音化**：软情绪也加入 `t d f`（`MOOD_SOFT_CONS`），
   并提高咬字率：词首 0.85 → 0.93、词中 0.60 → 0.80。
6. 功能词的音节表在 `util.js` 的 `HYMN_SYL`（想音 6 + 愿望 6 + 人称 4）。

#### 4）改后

| | 音节 | 带声母 | 韵尾 | 阻塞音 |
|---|---|---|---|---|
| 黎明海面 | 78 | **82%** | **32%** | **26%** |
| 夜之城 | 116 | **90%** | **30%** | **28%** |
| 森林 | 140 | **81%** | **21%** | **14%** |

`?selftest=1&short=1&n=3`：`nan=0`、`peak=0.691/0.818/0.849`、`WAV ok=true`、0 条 console error。

**取舍**：韵尾比例不能再往上抬了。塔语本身是"开音节为主"的语言（§3），
韵尾 30% 已经比它更"硬"；再高就会从"咏唱"滑向"念白"。
如果哪天觉得又变回元音流，先看这张表里的"韵尾 %"和"阻塞音 %"，这两个数掉下去就是原因。

> - 界面解释：`src/js/ui.js` 的 why 卡会显示这一首的想音三元组
>
> 实测六张示例的想音分布：`Wee/touwaka/erra`（黎明海面）、`Ma/ki/wa`（夜之城）、`Ma/jyel/wa`（森林）、`Wee/yea/ra`（人像）、`Was/au/erra`（黑白）、`Was/apea/ga`（抽象）。

1. 建一张 200 词左右的"伪塔语"词表（用 5.1 的规则批量生成，固定 seed，保证可复现）。
2. 每个乐句分配一个想音三元组（由图像特征推导，比如 `contrast` 高 → `Was`，`entropy` 高 → `paks`）。
3. 词尾音节时值 ×1.6，并让它的元音滑向相邻元音（元音过渡）。
4. 副歌（A′/A″）复用同一批词，形成"同一句话反复唱"的效果——这是塔语歌曲最明显的记忆点。
